# QuantumFlow

A mobile-first personal productivity app for habits, goals, study planning, focus sessions, quotes, and progress tracking.

## V1
- Daily habit completion
- Streaks and completion rate
- Study sessions and focus timer
- Goals and milestones
- Progress dashboard
- Rotating motivational quotes
- Local persistence with localStorage
- PWA foundation

## Roadmap
1. Supabase cloud sync and authentication
2. Offline-first sync
3. Notifications and reminders
4. Rich analytics and yearly heatmap
5. Capacitor Android APK

## Run
Open `index.html` or serve the folder over HTTP for PWA/service-worker support.
